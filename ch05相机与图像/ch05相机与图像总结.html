第五讲：相机与图像总结

本讲回答一个核心问题：三维世界中的点如何变为图像像素，以及深度从哪里来。它把第三讲的刚体变换 SE(3) 与后续的特征匹配、位姿估计和地图点三角化连接起来。

一、针孔相机：从三维点到像素

设空间点在相机坐标系下为 Pc = (X, Y, Z)T。针孔模型由相似三角形得到归一化平面坐标：

x = X / Z， y = Y / Z

再由焦距的像素单位表示和主点偏移，得到像素坐标：

u = fxX / Z + cx， v = fyY / Z + cy

其中 fx, fy 是横、纵方向焦距（像素），cx, cy 是主点。它们组成相机内参矩阵：

K = [ fx 0 cx ; 0 fy cy ; 0 0 1 ]

齐次形式可写为 Z·p = K·Pc。除以深度 Z 正是透视投影：同样大小的物体越远，像素投影越小。

二、外参与完整投影链

地图点通常写在世界坐标系中，而相机在运动。第三讲的刚体变换把它变到相机坐标系：

Pc = R·Pw + t，   R ∈ SO(3)， t ∈ R³

因此完整关系是：

Z·p = K(RPw + t) = K·T·Pw

K 是相机自身的内参，R, t（或 T）是外参。对视觉 SLAM 而言，外参随时间变化，估计它就是定位；同时反复观测同一特征点，才能恢复地图点位置。

三、镜头畸变与标定

真实镜头不是理想针孔。广角镜头常出现桶形畸变，鱼眼镜头畸变更强；装配不完全同轴还会产生切向畸变。常用归一化坐标 (x, y)，令 r² = x² + y²：

xr = x(1 + k1r² + k2r⁴ + k3r⁶)，  yr = y(1 + k1r² + k2r⁴ + k3r⁶)
xd = xr + 2p1xy + p2(r² + 2x²)，  yd = yr + p1(r² + 2y²) + 2p2xy

标定的目标是估计 K 以及 k1, k2, k3, p1, p2 等参数。若畸变不校正，重投影误差会系统性偏大，特征匹配与位姿优化都会受到影响。

四、双目：由视差得到深度

左右相机光心之间的距离称为基线 b。经过双目校正后，同一个空间点在左右图像上具有水平视差：

d = uL - uR，  Z = f·b / d

这是相似三角形的直接结果：点越近，左右成像位置差 d 越大；点越远，视差越小。双目能恢复绝对尺度，但关键难点是正确求出左右图像的对应点。纹理弱、重复纹理、遮挡和远距离小视差都会降低深度质量。因为最小可分辨视差约为一个像素，深度误差会随距离增大而明显放大。

五、RGB-D：直接测量深度

RGB-D 相机通常输出一张彩色图与一张对齐或可配准的深度图。它主要有两类深度获取方式：

方式工作原理特点与限制
结构光发射不可见的已知光图案；图案受物体表面形状影响发生形变，接收端据此求深度。本质上仍依赖三角测量；通常配有 RGB 相机。强日光会淹没红外图案，镜面、透明或吸光材料也容易导致无效深度。
飞行时间 ToF发射脉冲/调制光，测量光往返的时间差或相位差，按光速换算距离。无需左右匹配，但会受环境光、多路径反射、物体材质影响；多台主动红外设备同时工作时也可能互相干扰。

六、与视觉 SLAM 的关系

  • 单目：只有投影约束，单帧没有绝对深度；需要运动产生视差，且尺度天然不确定。
  • 双目：通过固定基线在单时刻获得深度，保留真实尺度；核心是标定、校正与视差估计。
  • RGB-D：直接提供稠密或半稠密深度，使初始化和建图更直接；但需处理缺失、噪声和传感器工作环境限制。

本讲主线：世界点先经外参 (R,t) 变到相机系，再经投影、畸变和内参变为像素；反过来，要从像素恢复三维，必须额外获得深度——它可以来自双目的视差，也可以来自 RGB-D 的主动测距。

七、学习检查

  1. 能从 Pw 写出它到像素 (u,v) 的完整投影过程。
  2. 能解释内参和外参的区别，以及为什么 SLAM 主要估计外参。
  3. 能推导并解释 Z = fb/d，特别是“远处深度不准”的原因。
  4. 能区分结构光与 ToF，并说出它们在强日光、玻璃、黑色吸光材质和多设备环境下可能出现的问题。
