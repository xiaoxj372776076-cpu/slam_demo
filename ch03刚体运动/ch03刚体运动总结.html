第三讲：三维空间刚体运动总结

根据文件夹“ch03刚体运动”中的 7 张 PPT 截图整理。截图重点集中在旋转的不同表示： 欧拉角、万向锁、四元数、四元数运算、四元数与角轴的关系，以及如何用四元数旋转空间点。

第三讲的核心问题是：如何在程序里准确、紧凑且稳定地表示相机或机器人的三维姿态与位姿。 SLAM 中的相机运动不仅有平移，还包含三维旋转，因此必须理解 SO(3)、SE(3) 以及常见旋转参数化方式。

一、刚体运动在 SLAM 中表示什么

刚体运动

刚体运动描述物体在三维空间中的位置和姿态变化。对视觉 SLAM 来说，通常就是相机坐标系相对于世界坐标系的变化。

  • 平移：相机中心移动到哪里。
  • 旋转：相机坐标轴朝向哪里。
  • 位姿：平移和旋转合在一起，常写作 T。

常用数学对象

旋转矩阵、旋转向量、欧拉角和四元数都能描述旋转，但适合的场景不同。工程中常用矩阵做变换，用四元数做姿态存储和插值。

  • SO(3)：三维旋转群，可用 3x3 旋转矩阵表示。
  • SE(3)：三维刚体变换群，可用 4x4 变换矩阵表示。

二、欧拉角：直观但有奇异性

1

欧拉角的定义

欧拉角把一次三维旋转分解为三次绕不同坐标轴的旋转。截图中采用常见的 Z-Y-X 顺序，也就是 yaw-pitch-roll。

  • yaw：绕物体 z 轴旋转，称为偏航角。
  • pitch：绕旋转后的 y 轴旋转，称为俯仰角。
  • roll：绕旋转后的 x 轴旋转，称为滚转角。
2

固定轴与动轴

欧拉角的轴可以定义为固定轴或动轴，旋转顺序也可以不同。因此同样三个数，在不同定义下可能表示不同姿态。

这也是使用欧拉角时容易出错的地方：必须明确旋转顺序、角度单位和坐标系约定。

3

万向锁

在 Z-Y-X 顺序中，如果 pitch 等于正负 90 度，第一次旋转和第三次旋转会绕到同一个轴上，系统失去一个自由度。

这就是万向锁。它说明欧拉角虽然直观，但不适合直接作为全局优化或连续姿态更新的主要表示。

三、四元数：紧凑、稳定、适合表示旋转

从复数到四元数

截图把四元数类比为复数的扩展：单位圆上的复数可以表示二维旋转，单位四元数可以表示三维空间中的旋转。

q = q0 + q1 i + q2 j + q3 k

也常写成实部和虚部的形式：

q = [s, v], s = q0, v = [q1, q2, q3]^T

虚部乘法规则

四元数有三个虚部 i、j、k。它们和自身相乘像复数，和彼此相乘像叉乘，因此乘法不满足交换律。

i^2 = j^2 = k^2 = -1
ij = k, ji = -k; jk = i, kj = -i; ki = j, ik = -j

四、四元数的常见运算

加法：qa ± qb = [sa ± sb, va ± vb]
模长：||q|| = sqrt(s^2 + x^2 + y^2 + z^2)
共轭：q* = [s, -v]
逆：q^-1 = q* / ||q||^2
数乘：kq = [ks, kv]
点乘：qa · qb = sa sb + xa xb + ya yb + za zb
单位四元数的模长为 1，此时逆等于共轭。表示旋转时通常要求四元数归一化，否则连续计算中会逐渐偏离合法旋转。

五、四元数与角轴

如果一个旋转可以表示为绕单位轴 n = [nx, ny, nz]^T 旋转角度 θ，那么对应的单位四元数为：

q = [cos(θ/2), nx sin(θ/2), ny sin(θ/2), nz sin(θ/2)]^T

反过来，也可以从四元数恢复角轴：

θ = 2 arccos(q0)
[nx, ny, nz]^T = [q1, q2, q3]^T / sin(θ/2)

这说明四元数、旋转矩阵和欧拉角之间可以互相转换。实际开发时，经常用四元数保存姿态，用旋转矩阵参与点坐标变换，用欧拉角输出给人看。

六、用四元数旋转空间点

空间点 p = [x, y, z]^T 不能直接和四元数相乘，需要先写成虚四元数：

p = [0, x, y, z] = [0, v]

若单位四元数 q 表示一次旋转，则旋转后的点为：

p' = q p q^-1

这条公式与旋转矩阵作用在向量上的效果一致。截图中也强调：可以验证 p' 仍然是虚四元数，也就是实部为 0。

七、几种表示方法对比

表示方式 维度/参数 优点 问题 常见用途
旋转矩阵 9 个数 直接作用于向量，组合旋转方便 有正交约束和行列式约束，参数冗余 坐标变换、投影模型、矩阵推导
欧拉角 3 个角 直观，方便描述 yaw-pitch-roll 依赖旋转顺序，存在万向锁 日志输出、人机理解、姿态显示
四元数 4 个数 紧凑、无奇异性、适合插值和连续更新 不够直观，需要归一化，q 与 -q 表示同一旋转 SLAM/机器人姿态存储、优化初值、轨迹文件
角轴/旋转向量 3 个数 最小参数，和李代数关系紧密 角度接近 0 或 π 时要小心数值问题 非线性优化中的局部扰动、Sophus/g2o/Ceres

八、学习第三讲时要抓住的主线

  • 旋转不是普通三维向量，不能直接相加相减来更新姿态。
  • 欧拉角适合理解姿态，但由于万向锁，不适合作为主要计算表示。
  • 单位四元数可以表示三维旋转，且比旋转矩阵更紧凑。
  • 点旋转公式 p' = q p q^-1 是理解四元数几何意义的关键。
  • 在代码中，要明确坐标系方向、旋转顺序、四元数分量顺序和单位约定。
